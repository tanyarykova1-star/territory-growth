# Territory Growth

A multi-page website for Territory Growth, a youth development and support center.

🌐 Live website: https://центр-ростакрд.рф/

## About the project

This website was developed as a real client project for a youth development center.

The goal was to create a clear and responsive website where visitors can learn about the center, explore its programs and specialists, view events, and quickly book a session.

## Features

- Responsive layout for desktop and mobile devices
- Multi-page website structure
- Information about specialists and programs
- Events and opening sections
- Useful materials section
- Search functionality
- Yclients booking integration
- Links to social media
- Reusable Astro components
- Content structured through separate data files

## Tech stack

- Astro
- HTML
- CSS
- JavaScript / TypeScript
- Pagefind
- Git / GitHub

## Project structure

The project uses reusable components and separate data modules for content such as:

- specialists
- services
- directions
- events

This makes the website easier to maintain and update.
